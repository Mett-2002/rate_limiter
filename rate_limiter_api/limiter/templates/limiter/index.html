Check a user's quota before performing an action.

Test the API

Start here

  1. Get an API key. Create an API client in Django Admin and copy its key.
  2. Open the browser tester. Paste the key and enter a user ID, such as alice.
  3. Send a Consume request. Each accepted request uses one slot. Check status reads the quota without consuming a slot.

Default rule: 5 accepted requests per user in the last 60 seconds. Each API client can have its own rule.

Why does opening Consume show 401?

The address bar sends a GET without your API key. Consume requires a POST with this header and a JSON body:

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{"user_id": "alice"}

Use the tester, CMD or Postman to send that request. An Admin login does not replace the API key.

The rolling window is (now - window, now]. A request exactly 60 seconds old stops counting under the default rule. Rejected requests do not extend the window.
